Why you might want this
It is the only option that costs nothing to build and never leaves anyone stuck. A small city where one administrator does the whole setup can finish in an afternoon without waiting on a second person who does not exist.
What it costs you
It is a claim, not a fact, and it can be wrong. There is no record of anyone taking responsibility, so when a request later goes out wrong there is nothing to look back at. It also puts a second source of truth next to the evidence the system already has.
What it needs from the role model
Nothing. Anyone allowed to edit the item can mark it. This option can be built before the user types exist.
