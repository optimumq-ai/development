What Texas law says
Loaded when the state was locked. Not editable — click a citation to read the statute text behind it.
4 rules
TX-0012
If a request is unclear, the city may ask the requestor to clarify it; for a very large request it may discuss narrowing the scope.
Tex. Gov't Code § 552.222(b)
TX-0013
A written clarification request must say what happens if the requestor does not reply in time.
Tex. Gov't Code § 552.222(e)
TX-0014
If no written reply has arrived by the 61st day after the clarification request was sent, the request is considered withdrawn.
Tex. Gov't Code § 552.222(d)
TX-0015
A good-faith clarification request pauses the 10-business-day clock for asking the attorney general, until the requestor replies.
City of Dallas v. Abbott, 304 S.W.3d 380 (Tex. 2010)

When is a request too vague?
